# CICIDS2017 Dataset Guide & Storage

This directory holds the raw and preprocessed data files for the AI-Powered Network Intrusion Detection System (AI-NIDS).

---

## 1. Official Dataset Overview

The dataset used in this research project is **CICIDS2017**, generated by the Canadian Institute for Cybersecurity (CIC) at the University of New Brunswick (UNB).

- **Official Source**: [Canadian Institute for Cybersecurity - CICIDS2017](https://www.unb.ca/cic/datasets/ids-2017.html)
- **Direct Citation**: Sharafaldin, I., Lashkari, A. H., & Ghorbani, A. A. (2018). *Toward Generating a New Intrusion Detection Dataset and Intrusion Traffic Characterization*. ICISSP.

---

## 2. Dataset Files

The dataset includes benign network traffic and attacks captured over 5 days (Monday to Friday, July 3–7, 2017):

| Day & File Name | Traffic / Attack Type Included |
|---|---|
| `Monday-WorkingHours.pcap_ISCX.csv` | Normal benign traffic only |
| `Tuesday-WorkingHours.pcap_ISCX.csv` | FTP-Patator, SSH-Patator brute-force attacks |
| `Wednesday-WorkingHours.pcap_ISCX.csv` | DoS (Slowloris, Slowhttptest, Hulk, GoldenEye), Heartbleed |
| `Thursday-WorkingHours-Morning-WebAttacks.pcap_ISCX.csv` | Web Attacks (Brute Force, XSS, Sql Injection) |
| `Thursday-WorkingHours-Afternoon-Infiltration.pcap_ISCX.csv` | Infiltration, MetaSploit |
| `Friday-WorkingHours-Morning.pcap_ISCX.csv` | Botnet (ARES) |
| `Friday-WorkingHours-Afternoon-DDos.pcap_ISCX.csv` | DDoS (LOIC) |
| `Friday-WorkingHours-Afternoon-PortScan.pcap_ISCX.csv` | Port Scan (Nmap) |

---

## 3. How to Download and Set Up

1. Visit [UNB CICIDS2017 Website](https://www.unb.ca/cic/datasets/ids-2017.html).
2. Download the `GeneratedLabelledFlows.zip` or individual CSV files from the `MachineLearningCVE` archive.
3. Place one or more CSV files into:
   ```bash
   data/raw/
   ```
4. Or use the **Dataset Analysis / Threat Analysis** upload feature directly inside the Streamlit web dashboard.

---

## 4. Directory Structure

- `data/raw/`: Place original unmodified CICIDS2017 CSV files here.
- `data/processed/`: Cached clean feature matrices and split datasets generated by the preprocessing pipeline.
- `data/sample/`: Lightweight synthetic/stratified sample datasets conforming to the exact CICIDS2017 78-feature schema for offline testing, CI/CD, and fast demonstration.

---

## 5. Security & Privacy Notice

- The `.gitignore` configuration explicitly excludes `data/raw/*.csv` and `data/processed/*.csv` from version control to prevent accidentally committing large or sensitive network traffic dumps.
- All analysis in this framework is strictly passive, offline, and research-oriented. No active network sniffing or packet injection is performed.
